# Independent development baseline

The planned v2.0.0 baseline uses the tested integrated main snapshot
`2c98dbadacdcd89c32c03ac41d588d7952161d9d` (Case Covers Platinum Edition V2).
Application source, assets, tests and settings behavior are preserved.

This development-history reset does not erase authorship. Case Covers derives
from Diego Bergonsi's [steam-case-covers](https://github.com/diegobergonsi/steam-case-covers).
Existing copyright notices, GPL-3.0-or-later licensing, asset licenses and
third-party attribution continue to apply. A new root commit records Shozei's
maintenance snapshot, not sole authorship of the inherited work.

Complete Git history, working files and previous published releases must be
verified in an external backup before any old refs or releases are removed.
Closed pull-request refs, public commit links and cached Contributors entries
can remain accessible on GitHub after branch and tag cleanup. A new root does
not guarantee removal of those cached objects.
