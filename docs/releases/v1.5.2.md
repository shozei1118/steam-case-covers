# Case Covers 1.5.2 — Platinum V2

Platinum covers now use layered silver and steel-blue metal reflections in the original rounded case geometry. A new original SVG trophy has an upright bowl, open handles, stem and foot, seated in a rounded extension of the lower lip. No completion text is drawn.

All 29 platform headers keep their original colours, logos and patterns. Normal covers and artwork fitting are unchanged. Cover Editor, per-game preferences, Batch, PNG export and Steam Apply retain the same final rendering workflow.

Validation: 286 regression tests passed (8 skipped); both source GUI selftests and targeted 29-platform Platinum checks passed. Windows EXE and installer are built and smoke-tested locally before distribution.

Limitations: Platinum completion is manual. Steam can briefly cache old artwork. Windows builds are unsigned.
